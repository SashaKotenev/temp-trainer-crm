# ТЕМП — CRM тренера

Функциональная демоверсия: клиенты, продажи, расписание, журнал тренировок, пакеты и оплаты.

## Использование

Откройте сайт GitHub Pages. Все исходные персонажи вымышлены. Данные сохраняются только в вашем браузере; экспорт JSON позволяет сделать копию. Оплаты — записи учёта, переводы денег не выполняются.

## Локальный запуск

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8768/. Проверка расчётов: `node check.mjs`.

## Публикация

GitHub Settings → Pages → Deploy from a branch → main → / (root). Сборка и зависимости не нужны.

## Граница демоверсии

Нет авторизации или серверной базы. Используйте вымышленные данные. Пакеты без срока действия, занятие списывается из первого пакета с остатком. Для совместной работы нужны серверное хранение, доступ по аккаунтам и резервное копирование.

## Спортивные пространства

Лёгкая атлетика: дистанции, интервалы, темп, старты. Футбол: состав, позиции, командные занятия и матчи. Плавание: стили, серии, объём и контрольные заплывы. Профиль тренера, формат работы и цель каждого направления редактируются. Спортивные данные сохраняются и входят в экспорт JSON.

Демо ограничено микроциклом 1–7 октября. Составы и контрольные тесты — вымышленные примеры. Объём выполнения считается по плановому объёму завершённых тренировок. Спортивный план не связан с финансовым расписанием и списанием пакетов.

## Библиотека тренера

База знаний содержит шесть упражнений и три шаблона. Поиск, фильтры по виду спорта и типу, избранное, создание и редактирование своих материалов. При переносе шаблона в спортивный план копируется содержание; дата и объём редактируются перед сохранением. Библиотека входит в экспорт JSON.

Карточки футбольных упражнений — краткий пересказ материала FIFA Training Centre со ссылкой на оригинал. Остальные карточки и дозировки шаблонов — редакционные демопримеры, параметры выбирает тренер. Статьи, видео, командный доступ и серверная база не входят в эту версию.
