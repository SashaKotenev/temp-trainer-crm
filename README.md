# ТЕМП — CRM тренера

Функциональная демоверсия: клиенты, продажи, расписание, журнал тренировок, пакеты и оплаты.

## Использование

Откройте сайт GitHub Pages. Все исходные персонажи вымышлены. Данные сохраняются только в вашем браузере; экспорт JSON позволяет сделать копию. Оплаты — записи учёта, переводы денег не выполняются.

## Локальный запуск

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8768/. Проверка расчётов: `node check.mjs`.

## Публикация

GitHub Settings → Pages → Deploy from a branch → main → / (root). Сборка и зависимости не нужны.

## Граница демоверсии

Нет авторизации или серверной базы. Используйте вымышленные данные. Пакеты без срока действия, занятие списывается из первого пакета с остатком. Для совместной работы нужны серверное хранение, доступ по аккаунтам и резервное копирование.
